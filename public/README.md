# Ícones e Imagens Estáticas

Esta pasta contém os arquivos estáticos do projeto:

- `favicon.ico` - Adicione seu favicon aqui
- `resume.pdf` - Adicione seu currículo em PDF aqui (acessível via /resume.pdf)

## Gerando um favicon

Você pode gerar um favicon usando ferramentas online como:
- https://favicon.io/
- https://realfavicongenerator.net/

Depois de gerar, substitua o arquivo `favicon.ico` nesta pasta.
