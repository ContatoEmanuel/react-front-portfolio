# Instruções para adicionar a foto de perfil

## Passo 1: Salvar a imagem
1. Abra a imagem que você enviou no chat
2. Clique com o botão direito e selecione "Salvar imagem como..."
3. Salve com o nome: `profile.jpg`

## Passo 2: Copiar para a pasta correta
Copie o arquivo `profile.jpg` para:
```
react-front-portfolio/public/assets/profile.jpg
```

## Estrutura de pastas
```
react-front-portfolio/
├── public/
│   ├── assets/
│   │   └── profile.jpg  <-- Coloque a foto aqui
│   └── resume.html
```

## Verificação
Depois de adicionar a foto, ela aparecerá automaticamente na seção Hero do portfólio.

Se a foto não carregar, o sistema usará um avatar gerado automaticamente com suas iniciais.
